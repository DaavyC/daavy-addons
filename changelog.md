##### 1.2.0
- Added a custom `Target Helper`.
  - Optional automation for saves, strikes, and healing.
  - The `NPCs Only` setting is also available for this `Target Helper`.
- Removed the **PF2e Toolbelt's Target Helper** automations (`Target Helper Automations`).

##### 1.1.1
- Added an `NPCs only` setting to `Target Helper Automations`.
  - When enabled, the automation only affects NPCs.

##### 1.1.0
- Added `Reach Control`, which limits the interaction distance for Doors, Stairways, and Tokens.
  - With the introduction of `Reach Control`, the module is no longer limited to PF2e.
- Features that depend on a specific system or module can only be enabled when all requirements are met.
- Improved the Settings interface.

`Reach Control` was originally forked from the **Arms Reach** module by **p4535992**. The version included in this module has been partially rewritten.

- Fixed minor bugs.
- Made internal changes that do not affect users.
